# Metrics Dashboard



What metrics matter for the business?

L4: RCT and other impact evaluation methods

## Build a Dashboard

From the event data, your data scientist or engineer can construct the metrics you have selected. Ideally, each metric has a directly responsible individual who is accountable for monitoring and improving the value over time.

For instance, “Time to Activate” can be calculated by counting the number of days between the first and last user actions required for completion of the "activation" stage. You can show these metrics on a dashboard that can be shared across the entire organization.

Out of the box, most commercial analytics platforms offer a pre-built reports for [funnel analysis](https://amplitude.com/docs/analytics/charts/funnel-analysis/funnel-analysis-build), [event segmentation](https://amplitude.com/docs/analytics/charts/event-segmentation/event-segmentation-build) and [user journeys/paths](https://amplitude.com/docs/analytics/charts/journeys/journeys-understand-paths).

  #### Payer/Partner Experience

  Governments/partners view/ should also be able to view and interact with your dashboards. The goal should be to increase external transparency because it will increase trust in your product/service.
