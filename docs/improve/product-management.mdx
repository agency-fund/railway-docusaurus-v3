# Product Management

## User Journey

Map all the [user journeys](../measure/user-journey.mdx). Ensure they makes sense to everyone involved.

## Problem Discovery

What is broken/missing in the user journey?

What do users want? Why?

What do funders/gov/partners want? Why?

Which effort will “move the needle” the most?
Ignore all other problems!

## Prototype and Validate

Research, Prototype (with AI!), Validate… on repeat, until
you discover a simple, intuitive UX

Don’t invent → Use established design patterns (WhatsApp?):
Follow their mental model (“Don’t make me think”)
Much cheaper to implement, and work better

Does it give the user(s) what they want?
Kill all prototypes that are not “usable”or “feasible”

## Build and Pilot

Draft a PRD, socialize it widely, get beat up… iterate, iterate, iterate

Prioritization criteria, Buy vs Build, Constraints

Recruit real users to test and validate what you build,
as you build

Add product telemetry before you pilot so you can immediately track L2 engagement (eg. Amplitude) 

## Experiment (+ Rollout)

Improve L2 and L3 metrics with experimentation

Pre/post comparison, A/B testing, Randomization

Use experimentation tools like Evidential

Review your user funnel to discover more problems

Rollout to all users after you iron out the kinks
